# Bitmap 使用场景

## 定义

Bitmap 是用 bit 位表示状态的数据结构，适合大规模布尔标记与集合运算。

## 原理

1. 每个元素映射到一个 bit 位。
2. 通过位运算实现高效查询、去重、交并集统计。
3. 用空间换取时间，且对连续整数 ID 场景特别高效。

## 应用场景

1. 用户签到。
2. UV 统计（近似或精确子场景）。
3. 黑白名单快速判定。
4. 海量 ID 去重。

## 高频面试点

1. Bitmap 与 HashSet 的空间对比。
2. Bitmap 适用数据范围与限制（通常要求可映射整数域）。
3. 位运算常见操作（置位、清位、判位）。

## 延伸问题

1. 超大范围稀疏数据如何优化（分段 Bitmap / RoaringBitmap）？
2. 如何与 Redis Bitmap 能力结合落地？
