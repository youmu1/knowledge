# Redis - Bloom Filter

## 定义

Bloom Filter 是一种空间效率高的概率型数据结构，用于判断元素是否“可能存在”或“一定不存在”。

## 原理

1. 使用位数组 + 多个哈希函数。
2. 插入时将多个位置置 1。
3. 查询时只要有一个位置为 0，即一定不存在；全部为 1 则可能存在（存在误判）。

## 应用场景

1. 缓存穿透防护。
2. 黑名单初筛。
3. 大规模集合存在性预检查。
