# Redis - Geohash

## 定义

Geohash 是将地理坐标编码为字符串的空间索引方法，可用于附近检索。

## 原理

1. 将经纬度映射为二进制并交织编码。
2. 通过前缀相近性表示空间邻近关系。
3. 在 Redis 中可结合 GEO 系列命令完成位置存储与范围查询。

## 应用场景

1. 附近的人。
2. 附近门店。
3. 位置聚合检索。
