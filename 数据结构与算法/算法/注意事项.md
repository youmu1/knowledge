# 算法 - 注意事项

## 定义

算法面试与实战中的通用执行规范，用于提升解题正确率、代码质量与沟通效率。

## 原理

1. 先明确问题边界，再确定时间复杂度目标。
2. 优先设计可验证的解法，再推进最优解。
3. 通过标准化测试用例降低隐藏错误。

## 应用场景

1. 面试白板编程。
2. 在线评测平台刷题。
3. 业务代码中的复杂逻辑实现。

## 高频面试点

1. 关注最优解（时间复杂度、空间复杂度）。
2. 熟练白板编写（变量命名、边界处理、函数拆分）。
3. 常见 API 要熟悉（集合、字符串、排序、二分）。
4. Test Case 编写与 Assert 规范：
  - 正常输入。
  - 边界输入（空、单元素、最大最小值）。
  - 异常输入（非法参数）。
  - 退化输入（重复、已排序、逆序）。

## 延伸问题

1. 如何从暴力解法系统推导到最优解？
2. 如何设计一套个人题解模板保证可复盘？
