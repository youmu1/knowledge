# 高效 Prompt 模板

> 记录与 AI 协作时的高效 Prompt 模式，提高协作效率。

## 🎯 代码重构类

### 模式：使用设计模式优化方法
```
使用设计模式优化{方法名}方法
```

**示例：**
```
使用设计模式优化listTradeCashFlows方法
```

**效果：** AI 会自动识别代码问题，提出策略模式等优化方案。

### 模式：消除重复代码
```
{方法A} 和 {方法B}存在重复的代码块
```

**示例：**
```
listTradeCashFlows 和 listMarginCashFlows存在重复的代码块
```

**效果：** AI 会提取公共逻辑，创建通用方法。

## 📝 文档生成类

### 模式：总结重构要点
```
请总结本次重构的要点，格式化为 Markdown，我将存入本地知识库
```

**效果：** AI 会生成结构化的重构文档，包含 Before/After、收益分析等。

### 模式：生成设计模式文档
```
请参考本次对话，生成一份关于{模式名}的文档，包含：
1. 模式概述
2. 核心组件
3. 解决的问题
4. 使用场景
5. 工程实践要点
```

## 🔍 代码理解类

### 模式：解释代码逻辑
```
解释{方法名}方法的业务逻辑，包括：
1. 输入输出
2. 核心流程
3. 业务规则
```

### 模式：查找相似模式
```
在代码库中查找类似的{模式/问题}，并分析是否可以统一优化
```

## 🛠️ 代码生成类

### 模式：基于模式生成代码
```
参考{知识库路径}中的{模式名}模式，为{新场景}生成代码
```

**示例：**
```
参考 C:\Users\tongyu\Documents\knowledge-base\patterns\factory-handler-pattern.md 中的 Factory+Handler 模式，为订单处理生成代码
```

### 模式：生成测试代码
```
为{类名}生成单元测试，重点关注{测试点}
```

## 📚 知识沉淀类

### 模式：生成学习总结
```
请总结本次对话中涉及的工程知识点，包括：
1. 设计模式的应用
2. 代码抽象的思路
3. 工程实践要点
按照 knowledge-base/ 的格式生成 Markdown 总结
```

### 模式：更新知识库
```
将本次{重构/学习}的要点添加到知识库，并更新 INDEX.md
```

## 🎨 最佳实践

### 1. 明确上下文
在提问前，先提供相关代码或文件路径：
```
查看 capital-server/src/main/java/.../CapitalFlowServiceImpl.java
使用设计模式优化 listTradeCashFlows 方法
```

### 2. 分步骤执行
对于复杂任务，分步骤进行：
```
第一步：分析代码问题
第二步：提出优化方案
第三步：执行重构
```

### 3. 引用知识库
在开始新任务时，引用相关模式：
```
@C:\Users\tongyu\Documents\knowledge-base\patterns\factory-handler-pattern.md
请参考这个模式来优化代码
```

### 4. 要求总结
每次重要对话后，要求生成总结：
```
请生成本次对话的总结，包含：
- 解决的问题
- 采用的方案
- 关键代码片段
- 学习要点
```

## 💡 Prompt 优化技巧

### 使用结构化描述
❌ **不好：**
```
优化这个方法
```

✅ **好：**
```
使用策略模式优化 listTradeCashFlows 方法，消除深层 if-else，提高可扩展性
```

### 提供具体示例
❌ **不好：**
```
生成一个 Handler
```

✅ **好：**
```
参考 TradeFeeHandler 的实现，生成一个处理期权费的 Handler
```

### 明确输出格式
❌ **不好：**
```
总结一下
```

✅ **好：**
```
请总结本次重构，格式化为 Markdown，包含 Before/After 代码对比和收益分析
```

## 🔄 常用工作流

### 重构工作流
1. **发现问题** → "分析这段代码的问题"
2. **提出方案** → "使用设计模式优化"
3. **执行重构** → "执行优化"
4. **验证效果** → "检查是否有编译错误"
5. **沉淀知识** → "生成重构总结文档"

### 学习工作流
1. **学习新概念** → "解释{概念}，并给出代码示例"
2. **实践应用** → "在项目中应用{概念}"
3. **总结沉淀** → "生成学习文档，存入知识库"
