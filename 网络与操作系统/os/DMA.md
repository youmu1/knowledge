# OS - DMA

## 定义

DMA（Direct Memory Access）是设备在 CPU 辅助下直接与内存交换数据的机制。

## 原理

1. CPU 配置 DMA 控制器（源地址、目标地址、长度）。
2. DMA 控制器负责数据搬运。
3. 传输完成后通过中断通知 CPU。

## 应用场景

1. 网络收发。
2. 磁盘 IO。
3. 高吞吐外设数据传输。

## 高频问题回答

### 数据拷贝过程？

1. 传统方式：设备 -> 内核缓冲 -> 用户缓冲，CPU 参与较多。
2. DMA 方式：设备到内存搬运由 DMA 负责，减少 CPU 数据搬运负担。
3. 零拷贝优化可进一步减少内核态/用户态之间的复制次数。
