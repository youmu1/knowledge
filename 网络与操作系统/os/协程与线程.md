# OS - 协程与线程

## 定义

1. 线程：操作系统调度的最小执行单元。
2. 协程：用户态轻量执行单元，通常由运行时或框架调度。

## 原理

1. 线程切换涉及内核调度和上下文切换，成本相对高。
2. 协程切换通常在用户态完成，成本相对低。

## 应用场景

1. 高并发网络服务。
2. IO 密集型任务编排。
3. 异步业务流水线。

## 高频问题回答

### 调度算法有哪些？

1. 先来先服务（FCFS）。
2. 时间片轮转（RR）。
3. 优先级调度。
4. 多级反馈队列（MLFQ）。

### 守护线程作用？

1. 守护线程用于辅助服务线程（如 GC、监控）。
2. 当仅剩守护线程时，JVM 可退出。

### 线程状态有哪些？如何转换？

1. NEW -> RUNNABLE -> RUNNING（逻辑执行）。
2. RUNNING -> BLOCKED/WAITING/TIMED_WAITING（锁竞争或等待条件）。
3. WAITING/TIMED_WAITING/BLOCKED -> RUNNABLE（条件满足或获取锁）。
4. RUNNABLE/RUNNING -> TERMINATED（执行结束）。

### 并行与并发的差异？

1. 并发：同一时间段内交替推进多个任务。
2. 并行：同一时刻多个任务真正同时执行（依赖多核）。
