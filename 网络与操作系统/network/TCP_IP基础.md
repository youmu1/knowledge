# Network - TCP/IP基础

## 定义

TCP/IP 是互联网通信协议体系，IP 负责寻址与路由，TCP 负责可靠传输。

## 原理

1. 分层设计：链路层、网络层、传输层、应用层。
2. 数据通过封装和解封装在层间传递。

## 应用场景

1. Web 服务通信。
2. 微服务内部 RPC。
3. 跨网段访问。

## 高频问题回答

### tcp三次握手与四次挥手

1. 三次握手用于双方确认收发能力与初始序列号同步。
2. 四次挥手用于双方独立关闭发送通道并确保数据发送完毕。

### IP掩码/子网划分/nat/ARP/mac地址/VPN原理等基础概念

1. IP 掩码与子网划分用于划分网络号与主机号。
2. NAT 用于私网地址与公网地址转换。
3. ARP 用于 IP 到 MAC 地址解析。
4. MAC 地址是链路层设备标识。
5. VPN 通过隧道与加密实现跨公网安全互联。
