# Network - HTTPS

## 定义

HTTPS 是 HTTP over TLS，通过加密与证书机制保障传输机密性与完整性。

## 原理

1. TLS 握手协商加密套件与会话密钥。
2. 证书链验证服务端身份。
3. 后续应用数据使用对称密钥加密传输。

## 应用场景

1. Web 登录与支付。
2. 服务间安全通信。
3. 零信任网络基础通信层。

## 高频问题回答

### 加密过程？

1. 客户端发起握手并发送支持的加密能力。
2. 服务端返回证书与协商参数。
3. 客户端验证证书并生成会话密钥材料。
4. 双方建立对称会话密钥后进行加密通信。

### 对称和非对称的区别？

1. 对称加密：同一密钥加解密，速度快，适合数据传输阶段。
2. 非对称加密：公私钥分离，速度慢，适合密钥交换和身份认证。

### CA证书的管理？

1. 证书由受信任 CA 签发并形成证书链。
2. 服务端需维护证书有效期、吊销状态与轮换策略。
3. 客户端通过信任根证书验证链路合法性。

### 几种加密方式的对比？

1. 对称：高性能，密钥分发困难。
2. 非对称：安全交换密钥，性能较低。
3. 摘要算法：用于完整性校验，不用于加密正文。

## Spring Boot 实践案例

1. 对外 API 必须强制 HTTPS，HTTP 301 跳转到 HTTPS。
2. 证书统一由网关层托管，应用层仅暴露内网端口。
3. Spring Boot 配置 TLS：
   - `server.ssl.enabled=true`
   - `server.ssl.key-store`、`server.ssl.key-store-password`
4. 证书到期监控应提前告警（如提前 30 天）。
