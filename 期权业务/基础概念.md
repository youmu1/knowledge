# 基础概念

## 定义

期权是赋予买方在约定条件下行使权利、卖方承担对应义务的合约。场外期权（OTC）由交易双方协商条款，无集中撮合，常见于结构化产品（雪球、障碍期权等）。

## 原理 / 结构要素

### 核心术语

| 术语 | 含义 |
|------|------|
| 标的（Underlying） | 期权所关联的资产，如股票、指数、商品 |
| 行权价（Strike） | 行使权利时的约定价格 |
| 名义本金（Notional） | 计算收益与风险的基准金额，非实际交割本金 |
| 合约乘数 | 每份合约对应的标的数量 |
| 起息日 / 到期日 | 合约生效日与最后有效日 |
| 期权费（Premium） | 买方支付给卖方的权利金 |

### 看涨 / 看跌

- **Call（看涨）**：买方有权以行权价**买入**标的。
- **Put（看跌）**：买方有权以行权价**卖出**标的。

### 买方 vs 卖方

| 角色 | 权利 | 义务 | 最大损益 |
|------|------|------|----------|
| 买方（Long） | 可行使或放弃 | 无 | 最大损失 = 期权费 |
| 卖方（Short） | 无 | 必须履约 | 理论上无限（裸卖 Call） |

### 欧式 vs 美式

- **欧式**：仅能在到期日行权。
- **美式**：到期日前任意时刻可行权。
- OTC 结构化产品多为**离散观察 + 到期结算**，行权逻辑由条款定义，不等同于标准美式期权。

### 场内 vs 场外

| 维度 | 场内 | 场外（OTC） |
|------|------|-------------|
| 合约 | 标准化 | 定制化 |
| 流动性 | 集中撮合 | 双边协商 |
| 信用风险 | 清算所担保 | 交易对手信用 |
| 典型产品 | 标准 Call/Put | 雪球、障碍、亚式 |

### 结算方式

- **现金结算**：按 Payoff 公式计算差额，以现金交割。
- **实物交割**：按行权价实际买卖标的（OTC 权益类多为现金结算）。

## 业务规则

1. 期权费在**开仓时**按约定方向收付（买方 OUT、卖方 IN，或反向取决于簿记视角）。
2. 名义本金用于缩放 Payoff，**平仓时可按剩余名义本金比例**计算结算金额。
3. 场外合约以**交易确认书**为准，系统要素必须与确认书一致。
4. 卖方需缴纳**保证金**；买方通常仅损失期权费（无追保义务，除非另有约定）。
5. 合约状态为 `Closed` 后不可再产生生命周期事件。

## 工程实现要点

- 领域模型区分 `Trade`（交易意图）、`Contract`（生效合约）、`Leg`（多腿结构中的单腿）。
- 簿记时校验：标的、名义本金、起息日 ≤ 到期日、行权价/障碍价在合理区间。
- 确认书编号与合约 ID 建立唯一映射，支持审计追溯。
- 方向字段（Long/Short、Buy/Sell）在全链路保持一致，避免现金流符号错误。

## 高频面试点

1. 期权与期货的核心区别：权利 vs 义务、期权费、非线性 Payoff。
2. 买方为什么风险有限、卖方为什么风险更大。
3. 名义本金与实际资金交割的关系。
4. 场内与场外期权在信用风险、定制性上的差异。
5. 欧式与美式对定价和工程实现的影响。
6. 现金结算 Payoff 的一般形式：`max(S - K, 0) × Notional / S₀`（Call 示例）。
