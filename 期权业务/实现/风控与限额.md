# 风控与限额

## 定义

风控系统对场外期权持仓进行限额检查与风险监控，防止单一客户、单一标的或整体 portfolio 的风险敞口超限。

## 原理 / 结构要素

### 限额类型

| 限额 | 说明 | 检查频率 |
|------|------|----------|
| 名义本金限额 | 单客户/单标的 Notional 上限 | 开仓实时 |
| Delta 限额 | 组合 Delta 敞口上限 | 日终 / 实时 |
| Vega 限额 | 波动率敞口上限 | 日终 |
| 集中度限额 | 单一标的占比上限 | 日终 |
| 保证金覆盖率 | 保证金 / 维持保证金 | 日终 |

### 检查时机

| 时机 | 检查内容 |
|------|----------|
| 开仓前 | 名义本金限额、客户资质 |
| 日终 | Delta/Vega/集中度、保证金 |
| 生命周期事件后 | 状态变更导致的风险重算 |

## 业务规则

1. 超限开仓请求**拒绝**，返回明确限额类型与当前占用。
2. 日终超限生成告警，不自动平仓（除非触发保证金强平）。
3. 部分平仓后限额占用按剩余名义本金比例释放。
4. 限额配置按客户等级、产品类型可差异化。
5. 风控检查结果写入审计日志，保留 5 年以上（合规要求）。

## 工程实现要点

- 服务：`RiskLimitService.check(trade)` → `CheckResult`（PASS / REJECT + reason）。
- 限额配置：DB 或配置中心，支持热更新。
- 与估值联动：日终 ValuationBatchJob 完成后触发 RiskBatchJob。
- 与保证金联动：维持保证金不足 → MARGIN_CALL → 强平流程。
- 聚合维度：Counterparty、Underlying、ProductType、Portfolio。

5. 风控与保证金系统如何联动。
