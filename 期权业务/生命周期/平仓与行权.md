# 平仓与行权

## 定义

平仓（Unwind）是合约到期前双方协商终止；行权（Exercise）是买方行使期权权利；放弃（Abandon）是到期 Payoff ≤ 0 时不行使权利。

## 原理 / 结构要素

### 事件类型

| 事件 | 场景 | 现金流 |
|------|------|--------|
| `UNWIND` | 提前终止（全部/部分） | 平仓结算金 + 交易费 |
| `EXERCISE` | 到期 Payoff > 0 | 行权结算金 |
| `ABANDON` | 到期 Payoff = 0 | 无 |

### 平仓定价

- **模型价**：按当前估值（NPV）作为平仓价。
- **协商价**：双方约定固定金额或折扣。
- **部分平仓**：按平仓比例 × 剩余名义本金计算结算金额。

### 全部 vs 部分平仓

| 类型 | 名义本金 | 状态 |
|------|----------|------|
| 全部平仓 | 剩余名义 → 0 | → UNWOUND → CLOSED |
| 部分平仓 | 剩余名义 -= 平仓部分 | 仍为 LIVE，继续观察 |

## 业务规则

1. 全部平仓后合约不可再触发观察事件。
2. 部分平仓后，观察与票息按**剩余名义本金**比例缩放。
3. 平仓结算金方向：原买方收取 NPV 为正的部分（依视角）。
4. 平仓产生交易费（`TRADE_FEE`），由 `TradeFeeHandler` 处理。
5. 已 KNOCKED_OUT 的合约不可 UNWIND（已终止）。
6. 欧式期权仅到期日可 EXERCISE；美式可在到期前 EXERCISE（如支持）。

## 工程实现要点

- API：`POST /contracts/{id}/unwind`，参数：`unwindRatio`（1.0 = 全部）、`settlementAmount`、`settlementDate`。
- 事件：`EventType.UNWIND`，Payload 含 `unwindNotional`、`settlementAmount`。
- 现金流：`PaymentOptionHandler`（结算金）+ `TradeFeeHandler`（费用）。
- 部分平仓：更新 `Contract.remainingNotional`，不变更 `status`（仍为 LIVE）。
- 全部平仓：`status` → UNWOUND → CLOSED。
- 估值：平仓时锁定 NPV 快照，作为结算依据审计。
