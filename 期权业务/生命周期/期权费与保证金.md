# 期权费与保证金

## 定义

期权费（Premium）是买方为获得期权权利支付给卖方的对价；保证金（Margin）是卖方（及有时买方）为覆盖履约风险而冻结或追加的资金。

## 原理 / 结构要素

### 期权费

| 维度 | 说明 |
|------|------|
| 支付时机 | 通常开仓时一次性支付 |
| 方向 | 买方 OUT（支出），卖方 IN（收入） |
| 金额 | 双方协商或模型报价 |
| 现金流类型 | `PREMIUM` |

### 保证金类型

| 类型 | 说明 |
|------|------|
| 初始保证金 | 开仓时冻结 |
| 维持保证金 | 日终检查后需维持的最低水平 |
| 变动保证金 | 估值变动导致的追加/释放 |

### 追保与强平

- 维持保证金不足 → 发出 `MARGIN_CALL` → 客户追加。
- 未在规定时间内追加 → 触发强平（Force Close / UNWIND）。

## 业务规则

1. 期权费在 OPEN 事件时生成现金流，支付日与起息日可不同（T+1/T+2）。
2. 买方通常无追保义务（损失上限 = 期权费），除非结构化产品另有约定。
3. 卖方初始保证金 = f(名义本金, Delta, Vega, 产品类型)，依风控模型计算。
4. 日终估值后更新维持保证金；不足则生成 `MARGIN_CALL` 事件。
5. 保证金释放：合约 CLOSED 或 UNWIND 后释放冻结资金。
6. 期权费不计入保证金计算基数（已交换的对价）。

## 工程实现要点

- 现金流：`PremiumHandler` 处理 OPEN 事件的 `PREMIUM` 类型。
- 保证金服务：独立模块，输入合约束与估值结果，输出保证金占用与追保金额。
- 事件：`MARGIN_CALL`、`MARGIN_TOP_UP`、`MARGIN_RELEASE`。
- 与估值联动：日终估值批完成后触发保证金重算 Job。
- 追保通知：生成待办 + 消息推送，记录 `marginCallDeadline`。

## 高频面试点

1. 期权费与保证金的区别（对价 vs 风险抵押）。
2. 为什么买方通常不需要追保。
3. 卖方保证金如何随标的价格变动（Short Call 的例子）。
4. 雪球卖方的保证金为何高于香草（路径依赖 + 敲入风险）。
5. OPEN 事件中期权费现金流的方向如何确定。
