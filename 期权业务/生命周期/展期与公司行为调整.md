# 展期与公司行为调整

## 定义

展期（Extension）是在原合约到期前延长有效期并可能调整条款；公司行为调整（Corporate Action Adjustment）是标的分红、拆股等事件导致合约要素的重新计算。

## 原理 / 结构要素

### 展期

| 要素 | 说明 |
|------|------|
| 新到期日 | 延长后的到期日 |
| 展期费 | 展期对价，双方协商 |
| 条款变更 | 行权价、障碍价等是否调整 |
| 事件 | `EXTENSION` |

### 公司行为类型

| 类型 | 影响 | 调整方式 |
|------|------|----------|
| 现金分红 | 标的价格下调 | 行权价/障碍价按比例下调 |
| 送股/拆股 | 标的数量变化 | 行权价按比例调整，数量反比 |
| 停牌 | 无法观察 | 观察日顺延或跳过 |
| 退市 | 合约提前终止 | 依条款协商结算 |

## 业务规则

1. 展期需双方确认，生成新 Terms 版本，旧版本归档。
2. 展期费在 EXTENSION 事件时生成现金流，由 `ExtensionFeeHandler` 处理。
3. 展期后观察日列表重新生成（延长部分追加观察日）。
4. 分红调整：除息日调整 K、B_in、B_out = 原值 × (1 - 分红率) 或依 ISDA 标准。
5. 拆股调整：K、B 除以拆股比例，名义本金不变。
6. 公司行为调整不产生直接现金流（除特殊条款），仅更新 Terms。
7. 调整生效日为除息日/除权日，非公告日。

## 工程实现要点

- 事件：`EXTENSION`、`DIVIDEND_ADJ`、`CORP_ACTION`。
- Terms 版本化：`termsVersion++`，旧版本 `readOnly = true`。
- `ExtensionFeeHandler`：EXTENSION 事件 → 展期费现金流。
- `DividendHandler`：分红相关现金流（如调整补偿）。
- 观察日列表：展期后调用 `ObservationDateGenerator` 追加。
- 公司行为：接入 `CorporateActionFeed`，批处理触发调整 Job。

5. Terms 版本化的工程意义（审计、重算估值）。
6. 停牌期间观察日如何处理。
