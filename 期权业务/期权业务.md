# 期权业务知识体系索引

## 使用规则

1. 每个主题对应一个独立 `md` 文件。
2. 索引只做导航，不写展开答案。
3. 每个知识点节点必须可枚举、可补充、可维护。
4. 子文件结构固定为：**定义 → 原理/结构要素 → 业务规则 → 工程实现要点 → 高频面试点 → 待补充项**。

## 维护规则

1. 新增产品结构先补到 [结构/](./结构/) 目录，再更新本索引。
2. 新增生命周期事件先补到 [生命周期/](./生命周期/) 与 [实现/生命周期事件设计.md](./实现/生命周期事件设计.md) 的事件枚举表。
3. 与现有工程模式文档交叉引用，不重复粘贴大段代码。
