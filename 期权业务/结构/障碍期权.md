# 障碍期权

## 定义

障碍期权（Barrier Option）的生效或失效取决于标的资产价格是否触及预设**障碍价**；分为敲入（Knock-In）与敲出（Knock-Out）两大类。

## 原理 / 结构要素

### 四种基本类型

| 类型 | 触发条件 | 效果 |
|------|----------|------|
| Up-and-Out | S ≥ B_up | 触及后期权**失效** |
| Up-and-In | S ≥ B_up | 触及后期权**生效** |
| Down-and-Out | S ≤ B_down | 触及后期权**失效** |
| Down-and-In | S ≤ B_down | 触及后期权**生效** |

In + Out 互补：未敲入 = 敲出状态，未敲出 = 敲入状态（对偶关系）。

### 观察类型

| 类型 | 说明 | 定价影响 |
|------|------|----------|
| 连续观察 | 任意时刻监测 | 触发概率最高，期权最便宜 |
| 离散观察 | 仅观察日判定 | 触发概率较低，期权更贵 |

国内 OTC 主流为**离散观察**（每日收盘或指定观察日列表）。

### Rebate（回扣）

敲出失效时，卖方可约定一次性 Rebate 补偿买方。

### Payoff 示例（Down-and-In Put）

- 未敲入：Payoff = 0
- 已敲入：Payoff = max(K - S_T, 0) × 缩放因子

## 业务规则

1. 敲入/敲出判定以观察日**收盘价**为准（条款约定，常见）。
2. 敲出后合约终止，产生 Rebate 现金流（如有）；不再参与后续观察。
3. 敲入后合约状态变为 Active（对 Knock-In）或 Inactive（对 Knock-Out）。
4. 同一合约不可重复敲入/敲出（已触发状态不可逆，除非条款另有复活条款）。
5. 障碍价与行权价相对位置决定产品风险特征（如 B < K 的 Down-and-In Put）。

## 工程实现要点

- 状态字段：`KNOCK_IN_STATUS` = `{NOT_TRIGGERED, TRIGGERED}`；`KNOCK_OUT_STATUS` 同理。
- 观察日批处理：`ObservationBatchJob` 遍历当日观察日合约，比较 Spot 与障碍价。
- 事件：`KNOCK_IN` / `KNOCK_OUT` 写入 Event Log，触发状态变更 + 估值重算。
- 敲出时若合约终止，后续观察日跳过；生成 Rebate 现金流（如有）。
- 与雪球关系：雪球的敲入本质是 Down-and-In 变体 + 票息条款。

## 高频面试点

1. Knock-In 与 Knock-Out 的区别与对偶关系。
2. 为什么离散观察比连续观察更贵。
3. 敲入后合约 Payoff 如何变化（以 Down-and-In Put 为例）。
4. Rebate 的作用与触发时机。
5. 障碍期权在雪球结构中的角色。
