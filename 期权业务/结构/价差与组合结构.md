# 价差与组合结构

## 定义

价差与组合结构（Spread & Combination）由多个期权腿（Leg）合成，用于表达特定风险偏好，Payoff 为各腿 Payoff 之和。

## 原理 / 结构要素

### 常见价差

| 结构 | 构成 | 适用观点 |
|------|------|----------|
| Bull Call Spread | Long K₁ Call + Short K₂ Call (K₁ < K₂) | 温和看涨 |
| Bear Put Spread | Long K₂ Put + Short K₁ Put | 温和看跌 |
| Calendar Spread | 同 K 不同到期日 | 波动率/时间结构 |
| Butterfly | Long K₁ + Short 2×K₂ + Long K₃ | 低波动预期 |

### 常见组合

| 结构 | 构成 | 特征 |
|------|------|------|
| Straddle | Long Call + Long Put（同 K） | 赌波动率上升 |
| Strangle | Long OTM Call + Long OTM Put | 成本更低，需更大波动 |
| Collar | Long Put + Short Call | 保护下跌、限制上涨 |
| Risk Reversal | Long Call + Short Put | 合成远期多头 |

### Payoff 合成原则

```
Total Payoff = Σ Leg_i Payoff × Direction_i × Quantity_i
```

Direction：Long = +1，Short = -1。

## 业务规则

1. 多腿结构**同时生效、同时终止**（除非某腿提前 Knock-Out）。
2. 每腿独立存储行权价、方向、数量；Trade 级别汇总风险。
3. 组合结构的整体 Greeks = 各腿 Greeks 代数求和。
4. 平仓时可全平或单腿平仓；单腿平仓后剩余腿变为独立合约（依条款）。
5. OTC 组合结构常以**打包报价**（单一期权费），系统需支持 Leg 级别与 Package 级别两套视图。

## 工程实现要点

- 数据模型：`Trade` → `List<Leg>`，每 Leg 含 `productType`、`strike`、`direction`、`notional`。
- 定价：各 Leg 独立定价后求和；或 Package 级别统一蒙特卡洛。
- 生命周期：Package 级别事件驱动所有 Leg；单 Leg 事件需同步检查 Package 一致性。
- 现金流：各 Leg 现金流分别生成，汇总到 Trade 级别展示。
- 风控：Package Delta = Σ Leg Delta；限额检查在 Package 与 Leg 两级执行。

## 高频面试点

1. Bull Call Spread 的 Payoff 图示与最大损益。
2. Straddle 与 Strangle 的区别与适用场景。
3. Collar 如何实现「保护下跌、让出上涨」。
4. 多腿结构的 Greeks 如何汇总。
5. 为什么 OTC 常以 Package 报价而非逐腿报价。
