# 亚式期权

## 定义

亚式期权（Asian Option）的 Payoff 取决于标的资产在**特定区间内的平均价格**，而非仅到期日价格，用于降低单点价格操纵风险。

## 原理 / 结构要素

### 两种主流形式

| 类型 | Payoff 依赖 | 公式 |
|------|-------------|------|
| 平均价期权（Average Price） | 平均价 A 与行权价 K | Call: max(A - K, 0)；Put: max(K - A, 0) |
| 平均执行价期权（Average Strike） | 到期价 S_T 与平均价 A | Call: max(S_T - A, 0)；Put: max(A - S_T, 0) |

### 平均方式

| 方式 | 说明 |
|------|------|
| 算术平均 | (S₁ + S₂ + ... + S_n) / n，更常用 |
| 几何平均 | (S₁ × S₂ × ... × S_n)^(1/n)，解析解更友好，价格更低 |

### Fixing 期

- **Fixing Start / Fixing End**：参与平均的价格观测区间。
- Fixing 期内每个观察日采集一个价格点，纳入平均计算。

## 业务规则

1. Fixing 期内每个观察日必须采集价格；缺失日按条款约定处理（跳过 / 沿用前日 / 报错）。
2. 平均价在 Fixing End 后确定，到期 Payoff 据此计算。
3. 算术平均亚式期权无 BSM 解析解，需蒙特卡洛或近似方法定价。
4. 亚式期权 Vega 通常低于等价香草，因平均化降低了波动率暴露。

## 工程实现要点

- Terms 存储：`fixingStartDate`、`fixingEndDate`、`fixingDates[]`、`averageType`（ARITHMETIC/GEOMETRIC）。
- Fixing 日批处理：采集 Spot 写入 `FixingPrice` 表，累计 running sum/count。
- Fixing End 后计算最终平均价，写入合约快照，供到期结算使用。
- 事件：`FIXING`（每日采集）、`SETTLE`（Fixing End 后到期结算）。

## 高频面试点

1. 亚式期权为何比香草更便宜（波动率 averaging 效应）。
2. 算术平均 vs 几何平均对 Payoff 的影响。
3. 平均价期权 vs 平均执行价期权的区别。
4. Fixing 期设计对工程批处理的影响。
5. 亚式期权在 OTC 中的应用场景（大宗商品、汇率）。
