# 结构要素对照表

## 定义

场外期权产品结构由一组可枚举的**结构要素**组合而成。面试时用「要素 → 产品」反向映射，可快速描述任意产品的核心条款。

## 原理 / 结构要素

### 跨产品统一要素表

| 要素 | 说明 | 典型取值 | 关联产品 |
|------|------|----------|----------|
| 标的 | 挂钩资产 | 个股、指数、商品 | 全部 |
| 名义本金 | 收益计算基准 | 100 万 ~ 数亿 | 全部 |
| 起息日 / 到期日 | 合约有效期 | T₀, T_maturity | 全部 |
| 行权价 (K) | 行使权利价格 | 100% × 初始价 | 香草、价差 |
| 障碍价 (B) | 触发条件价格 | 80% / 103% × 初始价 | 障碍、雪球 |
| 初始价格 (S₀) | 定盘基准 | 起息日收盘价 | 全部 |
| 观察频率 | 判定触发的时间点 | 每日 / 每月 / 每季 | 障碍、雪球、凤凰 |
| 观察日列表 | 离散观察具体日期 | `[2025-03-01, ...]` | 结构化产品 |
| 敲入条件 | 标的价格触及 B_in | Down-and-In: S ≤ B_in | 雪球、障碍 |
| 敲出条件 | 标的价格触及 B_out | Up-and-Out: S ≥ B_out | 自动赎回 |
| 票息 (Coupon) | 每期固定/条件收益 | 年化 15% × 持有天数/365 | 雪球、凤凰 |
| 红利 (Bonus) | 额外一次性收益 | 敲出时额外 2% | 增强型雪球 |
| 参与率 | 上涨收益分享比例 | 100% / 80% | 增强型、部分保护 |
| 保底 / 保护 | 最大损失下限 | 100% 本金保护 / 无保护 | 雪球 |
| 结算公式 | Payoff 计算规则 | 见各产品文档 | 全部 |
| 早终止条件 | 提前结束合约 | 敲出赎回、自动赎回 | 雪球、Autocall |
| 行权方式 | 欧式 / 美式 / 条款自定义 | 多为到期 + 观察日触发 | 全部 |
| 结算方式 | 现金 / 实物 | OTC 权益类多为现金 | 全部 |

### 要素 → 产品反向映射

| 产品 | 必备要素 | 可选要素 |
|------|----------|----------|
| 香草 Call/Put | 标的, K, 到期日, 名义本金 | 欧式/美式 |
| 障碍期权 | 标的, K, B, 观察类型, 到期日 | Rebate |
| 亚式期权 | 标的, K, Fixing 期, 平均方式 | 平均价/平均执行价 |
| 数字期权 | 标的, 触发条件, 固定 Payoff | Cash/Asset-or-Nothing |
| 雪球 | 标的, S₀, B_in, 票息观察日, 到期日 | 敲入保护, 红利 |
| 凤凰 | 标的, S₀, B_in, 票息观察日 | 条件票息（未敲入才付） |
| Autocall | 标的, B_out, 观察日, Coupon | 阶梯式早赎 |
| 价差 | 标的, K₁, K₂, 方向 | Bull/Bear Spread |

## 业务规则

1. 所有要素以**交易确认书**为唯一权威来源，系统录入不得缺项。
2. 障碍价通常以**初始价格百分比**表达，系统存储时同时保留绝对值与百分比。
3. 观察日列表必须**有序、无重复、落在起息日与到期日之间**。
4. 同一合约多腿结构（Spread）每腿独立存储要素，Leg 级别汇总到 Trade 级别。
5. 要素变更（展期、调整）产生新版本，旧版本只读归档。

## 工程实现要点

- 用 `ContractTerms` 或 JSON Schema 存储可变要素，不同 `ProductType` 对应不同 Schema。
- 校验器按产品类型注册：`SnowballTermsValidator`、`BarrierTermsValidator`。
- 观察日列表预生成存入 DB，批处理任务按列表驱动，避免运行时计算遗漏。
- 要素快照与生命周期事件绑定：事件触发时的 Terms 版本号写入 Event Payload。

## 高频面试点

1. 如何用 5 个要素向非技术人员描述一只雪球。
2. 敲入价与敲出价能否相同、相同时的业务含义。
3. 名义本金与标的数量的换算关系。
4. 离散观察日遗漏一天对敲出判定的影响。
5. 多腿结构的要素如何存储与版本化。
