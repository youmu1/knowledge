# 香草期权

## 定义

香草期权（Vanilla Option）是最基础的期权形态，分为 Call 和 Put，Payoff 为标的 price 与行权价之差的正值部分。

## 原理 / 结构要素

### Payoff 公式（到期时）

**Call：**

```
Payoff = max(S_T - K, 0) × Notional / S₀
```

**Put：**

```
Payoff = max(K - S_T, 0) × Notional / S₀
```

### 结构要素

| 要素 | 说明 |
|------|------|
| 行权价 K | 约定执行价格 |
| 到期日 T | 唯一行权日（欧式） |
| 期权类型 | Call / Put |
| 行权方式 | 欧式 / 美式 |

### OTC 常见变体

| 变体 | 说明 |
|------|------|
| 分段香草 | 不同价格区间不同参与率 |
| 增强型 | 上涨参与率 > 100%，下跌有保底 |
| Quanto | 标的与结算货币不同，含 FX 条款 |

## 业务规则

1. 欧式香草仅在到期日判定 Payoff；美式可在到期前任意日行权。
2. 买方支付期权费后，到期 Payoff ≥ 0；卖方最大收益为期权费。
3. 现金结算时，Payoff 以现金交割，不实际买卖标的。
4. 提前平仓（Unwind）按双方协商或模型公允价结算，非到期 Payoff 公式。

## 工程实现要点

- `ProductType.VANILLA_CALL` / `VANILLA_PUT` 对应最简单 Terms 结构。
- 定价可用 BSM 解析解，Greeks 直接公式计算。
- 生命周期事件：`OPEN` → `SETTLE` / `UNWIND` / `EXERCISE` / `ABANDON`。
- `EXERCISE`：Payoff > 0 时行权；`ABANDON`：Payoff = 0 时放弃，无结算现金流。
