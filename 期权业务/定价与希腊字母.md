# 定价与希腊字母

## 定义

期权定价是在给定市场参数下计算合约公允价值的过程；希腊字母（Greeks）描述期权价值对各输入变量的敏感度，是对冲与风控的基础。

## 原理 / 结构要素

### Black-Scholes-Merton（BSM）模型

**假设：**

1. 标的服从几何布朗运动，波动率恒定。
2. 无摩擦市场、无分红（可扩展）、可连续对冲。
3. 无风险利率恒定。

**欧式 Call 定价公式：**

```
C = S·N(d₁) - K·e^(-rT)·N(d₂)
d₁ = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T
```

Put 可通过 Put-Call Parity 推导：`P = C - S + K·e^(-rT)`。

**BSM 局限：**

- 常数波动率假设不成立（存在波动率微笑/偏斜）。
- 离散观察、路径依赖结构（雪球、障碍）需蒙特卡洛或 PDE 数值方法。
- 跳跃、分红、早偿条款需模型扩展。

### 隐含波动率（IV）

使 BSM 公式计算价格等于市场报价的波动率。IV 是**反解**结果，不是直接观测值。

### 希腊字母

| Greek | 含义 | 直觉 |
|-------|------|------|
| Delta (Δ) | ∂V/∂S | 标的价格变动 1 单位，期权价值变动量；对冲比率 |
| Gamma (Γ) | ∂²V/∂S² | Delta 的变化率；临近到期、ATM 时 Gamma 最大 |
| Vega (ν) | ∂V/∂σ | 波动率变动 1% 对价值的影响 |
| Theta (Θ) | ∂V/∂t | 时间流逝对价值的损耗（时间价值衰减） |
| Rho (ρ) | ∂V/∂r | 利率敏感度 |

**Long/Short 直觉：**

- Long Call：Delta > 0，Vega > 0，Theta < 0（时间损耗）。
- Short Call：Delta < 0，Vega < 0，承担 Gamma 风险。

### 波动率曲面

同一标的、不同行权价与到期日的 IV 构成曲面。OTC 结构化产品定价通常从曲面插值得到各 Tenor/Strikes 的 Vol。

### 离散观察 vs 连续观察

- **连续观察**：理论上每个时刻监测（障碍期权连续监控版本）。
- **离散观察**：仅在预设观察日判定（国内 OTC 主流）。
- 离散观察的敲出概率低于连续观察等价条款，因此**同条款离散观察期权更贵**。

## 业务规则

1. 日终估值使用**当日收盘参数**（Spot、Vol Surface、Discount Curve）。
2. 生命周期事件（敲入、平仓）发生后必须**重算估值**，不可沿用事件前快照。
3. 隐含波动率报价与绝对波动率（如 20%）需统一单位，避免系统间换算错误。
4. 临近到期时 Theta 与 Gamma 急剧变化，需关注对冲频率与模型稳定性。

## 工程实现要点

- 估值服务输入：`tradeId`、`valuationDate`、`marketDataSnapshotId`。
- 路径依赖产品（雪球、障碍）使用**蒙特卡洛引擎**或**有限差分**，与香草解析解分离。
- Greeks 计算：解析公式（香草）或 Bump-and-Revalue（结构化产品）。
- 估值结果写入 `ValuationResult` 表，保留模型版本与参数快照，支持重跑审计。
- 生命周期事件与估值批次的时序：先处理事件变更状态，再跑估值。
